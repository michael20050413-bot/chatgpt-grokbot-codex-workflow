# 新项目启动模板

只填写下面四项，将填好的项目卡随两段话分别复制。真实值仅保留在私人项目。

|项目卡输入|填写值|
|---|---|
|项目名称|〈项目名称〉|
|目标对话|原 ChatGPT：〈目标原对话〉；dots：〈指定 dots 对话〉；秘书Bot 主对话：〈主对话〉（未知可由秘书Bot 发现并读回）|
|Codex 工作区|〈Codex 工作区〉|
|授权范围|〈允许读取、修改、运行、发送、发布的范围及禁止事项〉|

由助手生成并回填：工作包编号（项目内唯一）、中转助手、Codex 任务 ID、轮次、当前状态、检查任务 ID/实际间隔/启用状态。未核实一律写“未知”。目标与大纲在原 ChatGPT 内先商定；无需另填一套重复配置。

## 第一段：发给原 ChatGPT

```text
请按「ChatGPT → Grok BOT → dots → Codex → ChatGPT 审阅」流程启动这个项目；以下是我的项目卡：
〈粘贴上面填好的四项〉
请先和我确定目标、大纲与授权范围，再生成唯一工作包编号、完整项目卡和首轮自包含任务书，选择适合的 Codex 模型及推理强度。首轮及每轮都写清材料、工作区、允许动作、交付、验收与停止条件。后续由本项目中转助手从本对话读取任务书、经指定 dots 交给正确项目 Codex，并把实际文件送回本对话审阅，不需要我逐轮复制。
请审阅实际文件后，在最终回复末尾使用【交接｜工作包编号｜轮次｜动作】……【交接结束】，动作仅“继续、完成、待材料、待用户决定”。“继续”必须附完整下一轮指令和下一轮编号；“完成”必须给回执与停止检查要求，并区分工作包完成与整个项目可提交。没有文件或证据就明确缺口，不虚构验收。
```

## 第二段：发给秘书Bot

```text
启动这个工作包。
〈粘贴同一张填好的四项项目卡〉
请安排本项目中转助手去指定原 ChatGPT 对话读取完整任务书及材料，发现并读回工作包编号、中转助手、指定 dots、Codex 工作区与任务 ID；绑定明确后交给指定 dots，后续不再要求我手动复制提示词。每轮记录请求、可设置、运行证实的模型和强度，无法核实写“未知”。
交付后取得实际文件并送回同一个原 ChatGPT 审阅，只处理完整最终交接块；“继续”则原样转交完整下一轮指令给 dots，“完成”则按回执收尾并停检，“待材料/待用户决定”则说明卡点并暂停依赖动作。
等待交付或审阅时请由有权限的 Grok BOT 设置默认每 5 分钟检查，读回实际任务 ID、间隔及启用状态；仍在生成就安静等，完整结果出现就当场处理。断线先查目标是否已收到，确认未到才补发，无法判断就报告；保留我的未发送草稿。请在我可见的秘书Bot 主对话主动报告第几轮已送审、下一轮已送到 dots、具体卡点或最终结果，无变化不用报，报完继续。工作包完成不代表整个项目已获提交授权。
```
