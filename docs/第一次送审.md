# 用两个对话做一次文件送审

准备一个空练习文件夹，把[两条练习材料](../examples/练习材料.txt)保存进去，用 Codex 打开这个文件夹。另开一个 ChatGPT 对话，两次审阅都回到这里。这个练习由你手动传文件。

**第一段发给 ChatGPT**，同时附上练习材料。

> 我想练习两轮文件送审。请写一份我能直接转交给 Codex 的首轮任务书，让它根据附件生成“索引-v1.md”，逐条保留编号与标题。首轮只做编号和标题，审阅时再安排添加分类。只允许在练习文件夹内生成索引。

**第二段发给 Codex**，在末尾粘贴刚才生成的完整任务书。

> 请在当前练习文件夹执行下面的任务书。完成后告诉我实际生成的文件名，让我能把它交回原对话审阅。

打开生成的 v1，检查能看到两条标题。把 **v1 文件本身**附到原 ChatGPT 对话，请它核对标题，并给出完整第二轮指令：保留标题，把甲归入“方法”、乙归入“案例”，另存为“索引-v2.md”。

把第二轮指令原样发回同一个 Codex 对话，再将实际 v2 文件附到原 ChatGPT。请它对照两条材料检查分类和标题。两项均通过、原对话明确回复工作包完成，就结束练习。若它只能看到文件名，先重新附上可打开的文件。

现在你已经做过两次传递。要让 Grok BOT 和 dots 接手这些步骤，请继续看[自动交接教程](从零上手.md)。
